# Reference boards

One folder per zone (`references/<zone-id>/`). Rishabh supplies the stills; nothing in a
zone is modelled or generated until its board exists (design doc, "Fidelity rules").

Name each still `<episode>_<mm-ss>_<short-description>.png`, for example
`ep01_06-12_cartrain-exits-shaft.png`, so proportions, colours, staging and lighting can
be traced back to the exact frame. Keep a `notes.md` beside the stills for anything the
frames do not show (scale cues, colour picks, which frame is canonical when they disagree).

These folders are deliberately empty in the repository: stills are copyrighted frames and
stay on Rishabh's machine unless the repository is private.
